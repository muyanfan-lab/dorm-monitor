高级设置 · 服务 / 特征 UUID
HC-08 / HM-10 通常是 FFE0 + FFE1。连不上时先用任意 BLE 扫描 App 确认模块实际广播的 UUID。 勾了过滤却看不到设备，取消勾选再连——有些模块被改过名。 必须和模块的数据口波特率一致。打开串口前请先关掉串口助手之类的程序，否则端口会被占用。 这四个阈值只用于网页判断要不要响，不会下发给板子；板子自己的阈值在 main.c 里（当前 DEMO_MODE=1：过流 1.5 A、超温 30 ℃、忘拔 30 秒；功率达到 0.5 W 才开始计时，低于 0.35 W 取消）。

HC-08：点“连接设备”→ 选 HC-08 即可。BLE 不需要配对、也不用输密码。
需要 Chrome / Edge（桌面或安卓）。iOS 的 Safari 不支持 Web Bluetooth，需改用 Bluefy 等浏览器。
串口模式是备用通道（HC-05 配对成电脑虚拟 COM 口），只在桌面版 Chrome / Edge 可用。
页面必须运行在 https:// 或 localhost 下，直接双击打开 file:// 可能拿不到设备权限。
